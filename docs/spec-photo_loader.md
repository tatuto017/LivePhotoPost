# 仕様: photo_loader.py

## 概要
データディレクトリを再帰スキャンして JPG 写真を読み込み、撮影日時を取得するモジュール。EXIF の DateTimeOriginal を優先し、なければファイルの作成日時をフォールバックとして使用する。

## クラス・データ構造

### `Photo` (dataclass)
写真ファイルの情報を保持する。

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `path` | `Path` | 写真ファイルの絶対パス |
| `takenAt` | `datetime \| None` | 撮影日時。EXIF の DateTimeOriginal を優先し、なければファイルの作成日時を使用する |

### `PhotoLoader`
ディレクトリをスキャンして写真を読み込むクラス。

**コンストラクタ引数**

| 引数 | 型 | 説明 |
| --- | --- | --- |
| `photoDir` | `Path` | 写真が格納されたルートディレクトリ |

## メソッド

### `loadPhotos(subDir: str | None = None) -> list[Photo]`
指定ディレクトリ以下の JPG ファイルを再帰的に読み込む。

- 対象拡張子: `.jpg` / `.jpeg`（大文字小文字を区別しない）
- `subDir` を指定した場合は `photoDir / subDir` 以下を対象とする
- 返却リストは撮影日時の**昇順**でソート。`takenAt` が `None` のものは末尾に配置
- パス中に `skip` ディレクトリを含むファイルは除外する（会場名未取得写真の退避先）
- 画像ファイルのオープンに失敗した場合、そのファイルはスキップして除外する

## 撮影日時取得仕様

| 優先順位 | 取得元 | 詳細 |
| --- | --- | --- |
| 1 | EXIF `DateTimeOriginal` (タグ ID: `36867`) | フォーマット `%Y:%m:%d %H:%M:%S` |
| 2 | ファイルの作成日時 (`st_ctime`) | EXIF が存在しない、または `DateTimeOriginal` がない場合のフォールバック |

- EXIF 取得・パースに失敗した場合は `None` を返し、呼び出し元でファイル作成日時へフォールバックする
- 画像ファイルのオープン自体に失敗した場合は `None` を返してそのファイルを除外する
