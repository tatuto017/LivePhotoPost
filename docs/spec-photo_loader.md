# 仕様: photo_loader.py

## 概要
データディレクトリを再帰スキャンして JPG 写真を読み込み、EXIF の撮影日時を取得するモジュール。

## クラス・データ構造

### `Photo` (dataclass)
写真ファイルの情報を保持する。

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `path` | `Path` | 写真ファイルの絶対パス |
| `takenAt` | `datetime \| None` | EXIF の DateTimeOriginal。取得できない場合は `None` |

### `PhotoLoader`
ディレクトリをスキャンして写真を読み込むクラス。

**コンストラクタ引数**

| 引数 | 型 | 説明 |
| --- | --- | --- |
| `photoDir` | `Path` | 写真が格納されたルートディレクトリ |

## メソッド

### `loadPhotos(subDir: str | None = None) -> list[Photo]`
指定ディレクトリ以下の JPG ファイルを再帰的に読み込む。

- 対象拡張子: `.jpg` / `.jpeg`（大文字小文字を区別しない）
- `subDir` を指定した場合は `photoDir / subDir` 以下を対象とする
- 返却リストは撮影日時の**昇順**でソート。`takenAt` が `None` のものは末尾に配置
- パス中に `skip` ディレクトリを含むファイルは除外する（会場名未取得写真の退避先）
- 画像ファイルのオープンや EXIF 読み込みに失敗した場合、そのファイルはスキップ（`None` を返して除外）

## EXIF 読み込み仕様

| 項目 | 内容 |
| --- | --- |
| EXIF タグ | `DateTimeOriginal` (タグ ID: `36867`) |
| 日時フォーマット | `%Y:%m:%d %H:%M:%S` |
| 失敗時の挙動 | `None` を返す（例外を握りつぶす） |
